# Contribuir

1. Llegeix `AGENTS.md`, les guies principals i l'ADR relacionat.
2. Crea una branca amb un canvi petit i vertical.
3. Afegeix validació, autorització, traduccions, tests i documentació.
4. Executa `pnpm format:check && pnpm lint && pnpm typecheck && pnpm test && pnpm build`.
5. Utilitza Conventional Commits.

No es modifiquen migracions aplicades, no s'ometen comprovacions i no es
versionen secrets.
