# Seguretat

Reporta vulnerabilitats de manera privada als responsables del repositori. No
obris una incidència pública amb dades personals, secrets o una PoC explotable.

L'arquitectura aplica denegació per defecte, RLS, validació d'entrada,
autorització per recurs i separació estricta entre claus públiques i secrets.
Consulta `docs/SECURITY_ARCHITECTURE.md`.
