# Internacionalització

Idiomes obligatoris: `ca`, `es`, `en`; català és el fallback. Les claus viuen a
`packages/i18n/messages`, sense concatenació de frases. El test de catàlegs
detecta claus absents, sobrants i valors buits. Dates, nombres, monedes, plurals
i unitats s'han de formatar amb el locale actiu.
