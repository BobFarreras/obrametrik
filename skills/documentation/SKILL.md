# Documentation

## Objectiu i ús

Mantenir documentació vinculada a comportament o decisions.

## Procediment

Revisa capçalera, comentaris, README, ADR, API pública, canvis, traduccions i
exemples. Contrasta amb codi i tests; elimina promeses no implementades.

## Resultat

Llista documents actualitzats, fonts i limitacions. No generis seccions buides
ni copiïs la mateixa explicació en múltiples fonts.
