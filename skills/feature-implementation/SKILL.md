# Feature implementation

## Objectiu i ús

Implementar una funcionalitat vertical; no per refactors sense comportament.

## Entrades i procediment

Requisits, criteris d'acceptació, model de dades i actors. Llegeix arquitectura,
analitza seguretat i dades, implementa verticalment, afegeix `ca/es/en`, tests,
accessibilitat i documentació, i executa totes les comprovacions.

## Resultat i restriccions

Resumeix codi, permisos, migracions, tests, riscos i deute. No desactivis
controls ni confiïs en identificadors del client.
