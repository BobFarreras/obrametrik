# Security review

## Objectiu i ús

Revisar canvis amb dades, auth, API, fitxers o IA; no substitueix testing.

## Procediment

Comprova autenticació, autorització, RLS, IDOR, validació, rate limit, secrets,
fitxers, logs, dependències, SSRF, XSS, CSRF, prompt injection i dades personals.
Traça entrada, trust boundary, decisió i efecte.

## Resultat

Troballes amb severitat, explotabilitat, evidència, impacte, correcció i test.
No incloguis secrets ni dades reals en PoC.
